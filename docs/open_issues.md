### Scope, зависимости и DoD G3

Результат: outcome автоматически рассчитывается по immutable event reference, владелец видит последующее движение, completeness и sample sizes; coding agent получает воспроизводимый versioned export. Digest независимо от realtime alerts агрегирует общую историю обоих markets. Ordinary raw candles90days; все referenced sources/events/outcomes/comparators сохранены.

10 основных AC: AC-03-04, AC-06-02/03/04/05/06/07, AC-07-06, AC-11-01/02. AC-10-01/02 завершаются schema/history upgrade fixtures; AC-08-01/10-04/12-03 остаются частичными до остальных subsystems, AC-07-05/09-06 требуют также agent isolation/consumer G4. Findings F08/F15/F16/F18/F20/F22/F25/F32 обновляются без потери остатка. Non-goals: orders/LLM/trading backtest, auto calibration, обязанность накопить прибыльную или минимальную live выборку, agent transport/consumer activation (G4), derivatives enrichment (G5).

DoD: все10 AC и затронутые persistence критерии подтверждены meaningful checks; latest required CI/self-review PASS, primary PR merged, automatic CD immutable source/image/backup/health/persistence/market PASS. Missing/late/recovered data не превращаются в zero return; immutable references и existing history сохраняются. Не требуется ждать60min реального event: horizons проверяются known-series/restart/fault fixtures. Agent analytics contract/liveness остаётся dependent scope.

Policies D12/D16/D17 сохраняются. Methodology v1 фиксирует price return и directed return в процентах; MFE>=0, MAE<=0 по highs/lows полного future1m окна (с нулём как отсутствием соответствующего excursion). Neutral: price return, max rise>=0/max fall<=0 и range, без continuation/reversal. Classification threshold frozen при event; missing ATR/noise явно UNCLASSIFIED. Target candle заканчивается точно observation+horizon, поздний worker не использует текущую цену. Settings horizons применяются к новым observations; старые events используют сохранённый snapshot либо agreed defaults5/15/30/60, не текущие будущие settings. Иная methodology создаёт новый outcome version, прежний результат не перезаписывается.

Comparator v1: предыдущие28days same instrument/market/TF; same UTC observation hour, тот же ATR%-quartile относительно полной доступной prior distribution, detector по frozen version/settings не срабатывает. Все baseline/outcome данные complete; comparison outcome заканчивается до event observation. Ближайшие означают самые недавние предыдущие подходящие windows, до20 неперекрывающихся; quartile boundaries/population count/source inputs/method фиксируются. Малый фактический N/неполная prior history показываются, sample size не объявляется достаточным для выводов о profitability. Outcome/comparator tasks ограничены batch и уступают current ingestion/recovery; measured capacity остаётся G6.

Storage schema1/NONE, versioned logical outcome/comparator/job/protected-source/digest namespaces в existing runtime table. Admission/event → pending jobs atomically; upgrade старой истории idempotent с durable cursor до retention. Complete used inputs и protections сохраняются одной transaction с результатом. Referenced raw keys и незавершённые диапазоны не удаляются. Retention bounded, без legacy/backups deletion; ordinary unreferenced candles older90days только после initial admission завершён. No physical DDL/JSON re-import; G2B image после записи новых owner fields не rollback-compatible, только forward-fix/verified compatible G3.

Export: read-only consistent SQLite snapshot, streaming NDJSON schema/versioned records с period/detector/version/market фильтрами и пагинацией; events/revisions, related episodes/revisions, settings/definitions/provenance, outcomes/comparators. CSV summary для агрегатов. Export не включает infrastructure/secrets/transport credentials. Decision-context readout использует только revisions available<=cutoff; analytics/outcomes явно отдельные поздние records.

Digest initiallyOFF, default60min, независимая delivery preference. One period has stable delivery identity; frozen content/attempts переживают restart, retry/unknown ack видны. Delayed restart доставляет последний доступный период и отмечает пропущенные, без burst старых notifications; enable начинает следующий interval. Alerts off/mute не останавливают outcomes/history или digest. Общий Telegram target permanent error виден в diagnostics, re-enable доступен владельцу.
